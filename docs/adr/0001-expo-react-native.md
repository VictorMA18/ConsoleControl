# ADR 0001 · Expo con React Native y TypeScript

## Estado

Propuesta

## Fecha

21/10/2026

## Contexto

El equipo necesita una app móvil y tiene unas 8 semanas hasta el MVP (11/12/2026). Hay que probar en celulares reales con poca configuración.

## Decisión

Usar React Native con Expo, TypeScript estricto y Expo Router para la navegación.

## Alternativas descartadas

- React Native sin Expo: exige más configuración nativa y el equipo tiene unas 8 semanas.

## Consecuencias

- Se puede probar en un celular real con Expo Go.
- Las librerías nativas deben ser compatibles con Expo.
- El proyecto se inicializa en T02.

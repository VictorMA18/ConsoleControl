# Reporte de defectos

| Campo | Valor                                                 |
| ----- | ----------------------------------------------------- |
| Tarea | T18 (TW-18) · TW-128                                  |
| Uso   | Plantilla para crear errores en Jira (tipo **Error**) |

## Severidades

| Severidad  | Cuándo                                         |
| ---------- | ---------------------------------------------- |
| Bloqueante | Impide usar la app o probar otros casos        |
| Alta       | Cobro o tiempo incorrectos, o pérdida de datos |
| Media      | Una función falla pero hay forma de seguir     |
| Baja       | Detalle visual o de texto                      |

## A quién se asigna

| Área                    | Persona |
| ----------------------- | ------- |
| Frontend                | RF      |
| Backend y base de datos | VM      |
| Diseño                  | JS      |

## Plantilla

```markdown
**Título:** [CP-0XX] Qué falla, en una frase

**Historia y caso:**
**Severidad:**
**Pasos para reproducir:**

1.

**Resultado esperado:**
**Resultado obtenido:**
**Dispositivo (modelo, Android, RAM, versión de la app):**
**Evidencia:**
**Asignado a:**
```

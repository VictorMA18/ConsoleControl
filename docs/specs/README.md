# Especificaciones de historias de usuario

Aquí va un archivo por historia de usuario, con el nombre `hu-001-nombre.md`. Cada archivo tiene la descripción, los criterios Given-When-Then y las tareas de Jira relacionadas. Se crea al empezar la historia.

La fuente de las historias es el backlog. No se inventan historias ni criterios.

## Plantilla

```markdown
# HU-00X · Nombre de la historia

## Historia

Como <rol>, quiero <acción>, para <beneficio>.

## Prioridad

Por definir

## Criterios de aceptación

- Given <contexto>, when <acción>, then <resultado>.

## Tareas Jira

- TW-n (Tn): descripción

## Notas técnicas

Decisiones o restricciones relevantes (enlaces a ADR si aplica).
```
